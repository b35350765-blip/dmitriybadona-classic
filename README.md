DmitriyBadona Classic

Classic textures for Minecraft Java Edition

DmitriyBadona Classic — это ресурс-пак, который придаёт Minecraft современным версиям классический стиль текстур, сохраняя атмосферу старых версий игры.
Информация
- Название: DmitriyBadona Classic
- Игра: Minecraft Java Edition
- Версия: 1.21.11
- Разрешение: 16×16
- Формат: Resource Pack (.zip)
Установка
1. Скачай ZIP-файл ресурс-пака.
2. Запусти Minecraft Java Edition.
3. Перейди в Настройки → Наборы ресурсов.
4. Нажми Открыть папку наборов ресурсов.
5. Перемести ZIP-файл в папку "resourcepacks".
6. Вернись в игру и активируй ресурс-пак.
